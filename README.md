# Yantratech Solutions — Vercel Ready

Responsive multi-page website for Vercel, with an authenticated content editor at `/admin`.

## Deploy with Vercel Drop
1. Open https://vercel.com/drop
2. Drag this ZIP (or the extracted folder) into Vercel Drop.
3. Deploy.

## Enable the admin panel and lead email
The admin editor saves public page copy in Vercel Blob. In the Vercel project, create a Blob store and add these Environment Variables for Production (and Preview if needed):

- `BLOB_READ_WRITE_TOKEN`: generated by the Vercel Blob store.
- `ADMIN_PASSWORD`: a unique, long password for the website editor.
- `ADMIN_SESSION_SECRET`: a separate random secret of at least 32 characters.
- `RESEND_API_KEY`: Resend API key for website enquiry delivery.
- `ENQUIRY_FROM_EMAIL`: sender address verified in Resend, such as `Yantratech Website <enquiries@your-verified-domain.com>`.

Redeploy after setting the variables. Open `https://www.yantratechsolutions.co.in/admin` and sign in. In the editor, choose a page, click **Edit page**, click highlighted copy in the preview to change it, or click an image to change its URL and alt text. Click **Save changes** to publish. Visitors receive the saved copy on their next page load. The editor changes visible copy and images; page layout, SEO metadata and form field definitions remain in the source files.

Both the quote and contact form email actions submit all entered form fields as a new lead to `sales@yantratechsolutions.co.in`. Email delivery requires the Resend variables above. Existing WhatsApp contact is retained. Add verified social profile URLs to the site before publishing them; none were supplied in the website ZIP.

The site includes mobile-responsive layouts, motion-reduced behavior, metadata, structured business data, `robots.txt`, `sitemap.xml` and `llms.txt`. Review page titles, business claims and social profile URLs against current company details before launch.

The website root contains `index.html`, so `/` serves the homepage.

## GitHub + Vercel
If the files are in a Git repository, import the repository into Vercel and keep the Root Directory as `./` (or the directory containing this `index.html`). Use Framework Preset **Other**. No build command or output directory is required.

`vercel.json` enables clean URLs, so `products.html` can be visited as `/products`, `contact.html` as `/contact`, etc.
